# [JS] Arrays, Objetos e Funções no JavaScript

Para esta aula, você deve:

- Clonar o repositório em seu computador e abrí-lo no VS Code;
- Instalar a extensão `Code Runner` no VS Code;
- Criar a sua branch e acessa-la;
- Cumprir os exemplos e o desafio em sua branch;
- Publicar sua branch neste repositório.
